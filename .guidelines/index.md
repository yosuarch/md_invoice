# Project Master Index

## Overview
This project is an internal B2B Invoicing App (quotations, invoices with PPN, payments, credit notes, delivery notes) built with CodeIgniter 4, CodeIgniter Shield, MariaDB and Bootstrap 5. Currency IDR.

## Core Documentation Reference
To ensure consistency and adherence to project standards, you MUST refer to the following files before performing any action:

1. **Project Goals:** See `intent.md` for the "Why" and "What".
2. **Database:** See `database.md` for the schema, conventions and business rules (source of truth).
3. **Technical Architecture:** See `architecture.md` for the "How" (Stack, Shield auth, MVC structure).
4. **UI/UX & Layout:** See `ui_ux_guidelines.md` for the "Look & Feel" (staff layout, screens, badges).
5. **Coding Standards:** See `rules.md` for the "Rules" (Naming, Security, Money handling, AI behavior).
6. **Roadmap:** See `roadmap.md` for the current phase and open questions.

## Operational Workflow
- **Analysis:** Always analyze the request against `intent.md`, `database.md` and `architecture.md`.
- **Design:** Ensure any new UI component follows `ui_ux_guidelines.md`.
- **Implementation:** Write code following the standards in `rules.md`.
- **Verification:** Cross-check the final output against all documents.
